# 夯拉榜

浏览器里的自由排位工具，经典评级为「夯 / 顶级 / 人上人 / NPC / 拉完了」。

在线使用：https://atrophes.github.io/hangla-board/

无需登录，图片与排版仅保存在当前浏览器中，不上传到服务器。线上地址与本地地址的浏览器存储相互独立。

## 部署

推送到 `main` 后，GitHub Actions 会运行检查并自动部署到 GitHub Pages。仅发布网站运行文件；测试素材、本地截图和日志不包含在部署产物中。

## 启动

```sh
python3 -m http.server 4180 --bind 127.0.0.1
```

打开 http://127.0.0.1:4180/ 。无需构建，图片和编辑记录保存在当前浏览器的 IndexedDB 中。

## 使用

- 粘贴、批量上传或拖入图片：同时加入候选区与画布，自动寻找不重叠的空位；同一行放满后向右扩展，可横向滚动查看。
- 拖动画布图片可跨评级自由摆放；选中后拖拽四角或使用底部缩放滑块，保持原始长宽比。
- 图片的 ×、底部移除按钮或 Delete / Backspace 仅移除画布实例。候选区的 + 可以重新添加，也可以添加多份。
- 候选区的编辑菜单管理名称和候选图片；候选删除也不会删除已有画布实例。
- 向上 / 向下扩展增加无文案留白；「收回上方 / 下方留白」独立移除扩展，不影响后续排版。图片越过边界时画布自动容纳完整图片。
- 「编辑评级」可以修改名称、颜色、顺序，并在顶部或底部添加评级。
- 顶部「复制图片」直接复制当前完整榜单，无需打开导出预览或下载文件。
- 导出先预览，再选择位置保存 PNG，并自动复制图片到剪贴板；取消保存不会下载。不支持文件选择的浏览器会明确提示，可右键预览图另存为或启用浏览器的「每次询问保存位置」。剪贴板失败可单独重试。
- 导出只包含评级背景与完整图片，无标题、文件名标签、日期、水印或编辑控件。
- Cmd / Ctrl + Z 撤销，Cmd / Ctrl + Shift + Z 重做。最近 30 步历史随画布一起保存在 IndexedDB，刷新后仍可使用；旧版本没有保存的历史无法补回，可使用收回留白。选中图片后方向键微调，Shift + 方向键加大步幅。

预览与导出使用同一套画布坐标和背景 SVG。基础宽度导出为 1600 像素，横向扩展增加输出宽度；超大画布会等比降低输出分辨率，以容纳整张图片。

## 检查

```sh
node --check app.js
node --test tests/*.test.mjs
```

测试覆盖图片比例、自动扩展和空位、收回留白、历史保存和旧数据迁移，以及保存/复制、取消和权限失败流程。
